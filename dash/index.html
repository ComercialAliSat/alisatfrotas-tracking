Nova integração
Planilha Google: cole aqui a URL do seu Apps Script Web App (Extensões → Apps Script → Implantar → App da Web). Qualquer outro webhook (Zapier, Make, um CRM novo) também entra aqui.
Escolha o campo de origem na lista (ou "Campo personalizado…" para digitar um nome técnico) → nome enviado ao destino. Sem nenhum campo aqui, manda o payload inteiro.
Autenticar com uma API (ex.: um CRM) — opcional
Para chamar uma API autenticada (não apenas um webhook que recebe de nós). A chave fica só no Cloudflare — aqui você só aponta o nome da variável, nunca digita a chave.
Precisa já existir em Pages → Settings → Environment variables.
Para um receptor que É SEU (Apps Script, n8n) verificar que a chamada veio daqui — diferente da autenticação de API acima.
Já existe um secret salvo — deixe em branco para mantê-lo.
